## 0-1. 독립 사이트·앱 이전 (2026-11-02 결정, ①② 완료 V88~V90)
- 이유: 기기마다 저장 상태가 달라 저장 코드로 옮기는 게 불편 → 아이디·비밀번호 로그인 + 계정 저장 + 멀티플레이를 원함. 친구들은 모바일과 PC를 함께 씀.
